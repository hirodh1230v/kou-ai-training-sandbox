# こていひへらしくん Issue 一覧

要件メモ（`docs/my-budget-app-requirements.md`）をIssueに分解したもの。
1 Issue = 1つの小さな機能の方針で、合計7本。

## 取り組み順序

依存度の低いものから着手する。

```
[MVP（必須機能）]
1. 固定費を登録するフォームを作る
2. 固定費の一覧を表示する
3. 月合計を自動計算して表示する

[あるとうれしい機能]
4. 固定費を編集できる
5. 固定費を削除できる
6. 前月との比較を表示する
7. 月合計のグラフを表示する
```

---

## Issue 1: 固定費を登録するフォームを作る

カテゴリ: MVP

### 目的

ユーザーが「Netflix」「家賃」などの固定費を登録できるようにする。
この機能があることで、後の「一覧」「月合計」機能の土台になる。

### やること

- 入力フォーム画面を作る
  - 固定費の名前を入力（テキスト欄）
  - 月額金額を入力（数値欄）
  - 支払日を入力 or 選択（例: 毎月15日）
- 「追加」ボタンを設置する
- ボタンを押したら、入力した内容が一覧データに追加される処理を作る

### 完了条件 DoD

- フォームに名前と金額を入力する
- 「追加」ボタンを押す
- 一覧エリアに新しい行として表示される
- リロードしたら消えてOK（localStorage保存は別Issue）

### やらないこと

- 編集 → Issue 4
- 削除 → Issue 5
- 永続保存（localStorage）→ 別Issue
- カテゴリ分け → 今回の要件外
- 細かいバリデーション
- グラフ表示 → Issue 7

### 確認方法

- localhostでアプリを開く
- 「Netflix / 1490円 / 毎月15日」を入力して「追加」ボタンを押す
- 一覧に「Netflix 1490円 15日」が表示される
- もう1件追加して2件並べばOK

## Issue 2: 固定費の一覧を表示する

カテゴリ: MVP

### 目的

ユーザーが登録した固定費を一覧で見られるようにする。

### やること

- 登録された固定費を一覧形式で画面に表示する
- 各行に「名前」「月額金額」「支払日」を表示する
- 0件の時は「まだ登録されていません」のメッセージを表示する

### 完了条件 DoD

- サンプルデータ（2件以上）が一覧に並んで表示される
- 各行に「名前」「金額」「支払日」が正しく表示される
- データが0件の時、空メッセージが表示される

### やらないこと

- 並び替え・検索・フィルタ
- 編集 → Issue 4
- 削除 → Issue 5
- グラフ表示 → Issue 7
- 永続保存（localStorage）→ 別Issue

### 確認方法

- localhostでアプリを開く
- 2件登録する（例: 「Netflix 1490円 15日」「家賃 70000円 1日」）
- 一覧エリアに2件並んで表示
- 名前・金額・支払日がそれぞれ正しく見える
- データを全部消した時に空メッセージが出る

## Issue 3: 月合計を自動計算して表示する

カテゴリ: MVP

### 目的

ユーザーが「月にいくら固定費を払っているか」を一目で把握できるようにする。
「固定費を減らしたい」という要件の達成度を測る指標になる。

### やること

- 一覧データから月額金額を合計する処理を作る
- 計算結果を画面の目立つ場所（一覧の上 or 下）に表示する
- 表示形式は「合計: 75,490円」のように分かりやすく

### 完了条件 DoD

- 一覧に登録された固定費の月額合計が画面に表示される
- 固定費を追加するたびに合計が再計算される
- 0件の時は「合計: 0円」と表示される

### やらないこと

- 年合計（12倍計算）→ 別Issue or 要件外
- 過去月との比較 → Issue 6
- 平均、最高額、最安額の表示 → 要件外
- グラフ表示 → Issue 7
- カテゴリ別の合計 → 要件外

### 確認方法

- localhostでアプリを開く
- フォームから2件登録（例: 「Netflix 1490円」「家賃 70000円」）
- 画面に「合計: 71,490円」が表示される
- もう1件追加（例: 「楽天モバイル 3000円」）
- 「合計: 74,490円」に自動で更新される
- 全部消したら「合計: 0円」が出る

## Issue 4: 固定費を編集できる

カテゴリ: あるとうれしい

### 目的

ユーザーが登録した固定費を後から修正できるようにする。
タイポや料金変更（例: サブスク値上げ）に対応できる。

### やること

- 一覧の各行に「編集」ボタンを設置
- 編集ボタンを押すと、その行の名前・金額・支払日を編集できる状態にする
- 「保存」ボタンで変更を反映、「キャンセル」ボタンで取り消し

### 完了条件 DoD

- 一覧の任意の行を編集できる
- 名前・金額・支払日を変更して保存できる
- キャンセルすると変更が反映されない
- 編集後、月合計（Issue 3）が再計算される

### やらないこと

- 一括編集
- 編集履歴の保存
- 永続保存（localStorage）→ 別Issue

### 確認方法

- 「Netflix 1490円」を登録
- 編集ボタン → 金額を「1980円」に変更 → 保存
- 一覧の表示が「Netflix 1980円」に変わる
- 合計も再計算される

## Issue 5: 固定費を削除できる

カテゴリ: あるとうれしい

### 目的

ユーザーが不要になった固定費（解約したサブスク等）を削除できるようにする。
固定費削減の達成感が見える化される。

### やること

- 一覧の各行に「削除」ボタンを設置
- 削除ボタンを押すと、該当行が一覧から消える
- 削除前に確認ダイアログを出す（誤操作防止）

### 完了条件 DoD

- 一覧の任意の行を削除できる
- 削除確認のダイアログが出る
- 削除後、月合計（Issue 3）が再計算される

### やらないこと

- 一括削除
- 削除した項目の復元（ゴミ箱機能）
- 永続保存（localStorage）→ 別Issue

### 確認方法

- 「Netflix 1490円」「家賃 70000円」を登録
- Netflixの削除ボタン → 確認ダイアログでOK
- 一覧からNetflixが消える
- 合計が「70,000円」に変わる

## Issue 6: 前月との比較を表示する

カテゴリ: あるとうれしい

### 目的

ユーザーが「先月と比べて固定費が増えた／減った」を一目で確認できるようにする。
固定費削減の進捗が見える化される。

### やること

- 月ごとの固定費合計をデータとして持つ
- 「今月の合計」「先月の合計」「差額（+/-）」を表示する
- 差額が減ってる時は緑色、増えてる時は赤色など視覚的に分かりやすく

### 完了条件 DoD

- 画面に「先月: XX,XXX円」「今月: XX,XXX円」「差額: -X,XXX円」が表示される
- 差額の符号と色で増減が分かる
- 比較できるデータがない場合（初月）は「比較できる前月データがありません」と表示

### やらないこと

- 過去3ヶ月以上の比較
- 折れ線グラフ → Issue 7
- カテゴリ別比較
- 永続保存（localStorage）→ 別Issue

### 確認方法

- 「先月70,000円」「今月67,000円」のデータがある状態でアプリを開く
- 「先月: 70,000円」「今月: 67,000円」「差額: -3,000円」（緑色）が表示される
- 初月だけのデータの時は「比較できません」のメッセージ

## Issue 7: 月合計のグラフを表示する

カテゴリ: あるとうれしい

### 目的

ユーザーが固定費の推移を視覚的に確認できるようにする。
数字だけより直感的に「減ってる／増えてる」が分かる。

### やること

- 月ごとの固定費合計を折れ線グラフで表示する
- グラフのX軸に月、Y軸に金額を取る
- グラフライブラリを使う（例: Chart.js、Recharts など）

### 完了条件 DoD

- 月合計のデータがある状態でグラフが描画される
- 3ヶ月以上のデータがあれば推移が見える
- 1ヶ月だけのデータでも点が1個表示される

### やらないこと

- カテゴリ別グラフ
- 円グラフ、棒グラフ（折れ線のみ）
- グラフのカスタマイズ（色変更など）

### 確認方法

- 3ヶ月分のサンプルデータ（4月: 75,000円 / 5月: 73,000円 / 6月: 70,000円）を用意
- アプリを開くと折れ線グラフが表示される
- 右肩下がりの線になっていれば固定費削減が視覚的に分かる
