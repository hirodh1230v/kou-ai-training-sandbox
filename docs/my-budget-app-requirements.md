# 私の家計簿アプリ要件

## アプリ名

こていひへらしくん

## 使う人

- 自分
- スマホで週1ペースで使う（固定費の見直しがメインなので毎日入力する必要はない）

## 解決したい悩み

- 毎月の固定費（家賃・サブスク・通信費・光熱費など）が見えにくく、減らせるところが分からない
- 月にいくら固定費がかかってるか、ざっくり把握したい

## 最初に必ずほしい機能

- 固定費を登録できる
- 登録した固定費の一覧を見れる
- 月合計が自動計算される

## あるとうれしい機能

- 固定費の編集
- 固定費の削除
- 前月との比較
- グラフ表示

## 今回やらないこと

- カテゴリ分け（通信費・保険など）
- 削減目標の設定
- PWA化（ホーム画面に追加）
- 通知 / アラート
- CSV出力
- 銀行・カード連携（安全ポリシーで禁止）
- ユーザー登録・ログイン（個人情報を扱わないため）
- 本番公開（Lv4までlocalhostのみ）

## 完成条件

- localhost で固定費を登録できる
- 一覧と月合計が表示される
- PR で差分と検証結果を説明できる

## 技術構成

Next.js（推奨構成）
